Comparing scientific data by its shape

Two simulation time steps can differ in a million values and still share the same structure — the same peaks, the same ridges, the same way regions merge as you sweep a threshold.

At CVIT I research computational-topology methods for comparing scientific scalar-field data using persistence distortion distance (PDD), extremum graphs, merge trees and topology-based analysis.

The work is engineering as much as mathematics: extending C++ PDD implementations, automating ParaView/TTK pipelines, and building Python tooling that validates thresholds and intermediate outputs before large batch experiments run.

ChaosAgent — Reliability Evaluation Platform for Tool-Using AI Agents

A request is sent. The operation succeeds. Then the response vanishes. Did it happen? An agent that guesses will either give up on work that was done — or do it twice.

ChaosAgent is a stateful reliability-evaluation platform built to study exactly that moment. It injects deterministic failures into synthetic business workflows, then evaluates how an agent recovers — judged not by what the agent says, but by authoritative state and event evidence.

  • Python
  • PostgreSQL
  • FastAPI
  • Server-Sent Events
  • React
  • OpenTelemetry

Inside the tower

How the platform is built

Every experiment flows down through the same building: a run is exposed over the API, scheduled by the orchestrator, perturbed by the failure injector, and finally judged against the evidence stored at the foundation.

The orchestration layer is where correctness lives: leases are taken safely, mutations are idempotent, and approvals are durable — so a retry after an ambiguous failure cannot produce a second effect.

PraxisMirror

Real processes don't follow one case ID. A container, a vessel and a booking each carry their own history — and those histories intersect at shared events.

PraxisMirror ingests OCEL 2.0 object-centric event logs deterministically and computes analytics that carry their evidence with them — so a number can never quietly be reused somewhere it doesn't belong.
